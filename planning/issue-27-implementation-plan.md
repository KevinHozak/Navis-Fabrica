# Routing-P3 implementation plan

## User Review Required
None. Issue #27 authorizes scoped implementation, verification, commit, push, and PR creation. Do not merge.

## Acceptance Criteria

| Criterion | Implementation | Verification |
| --- | --- | --- |
| Safe fallback | Add a versioned deterministic fallback evaluator. It accepts only configured failure/quota triggers at a safe checkpoint, then reuses P2 eligibility and ranking while applying local-only policy and user override. | Unit fixtures reject disabled/unconfigured triggers, missing checkpoints, privacy violations, and unsafe run states; verify eligible manual choice. |
| Auditable, bounded handoff | Return a decision audit with policy version, trigger, source/target route, checkpoint, rejected providers, and reason. Exclude visited providers, cap handoffs, and carry completed side effects as non-repeatable context. | Fixtures cover route loops, hop limits, provider exhaustion, and already completed side effects. |
| Calibration | Add a fixture-driven calibration summary for outcome rate, latency, and available usage by provider/model. Unknown or stale usage remains explicitly unknown; no policy is auto-tuned. | Representative samples verify aggregation and unknown usage behavior. |

## Proposed Changes
- `src-tauri/src/routing.rs`: fallback policy/evaluator and calibration report as deterministic pure functions.
- `src-tauri/src/lib.rs`: bounded Tauri command for fallback evaluation; input validation.
- `src/settings.ts` and `src/RunsPanel.tsx`: typed fallback request and user-visible decision review before starting a handoff.
- `src-tauri/permissions/autogenerated/`: narrow command permission.
- `planning/issue-27-implementation-plan.md`: this mapping (UTF-8 BOM).

## Verification
- Focused Rust routing fixtures, full Rust suite if feasible, frontend build/typecheck, `cargo fmt --check`, `cargo check --locked`, and `git diff --check`.
- No live provider or account data will be claimed; calibration uses persisted local run metadata or synthetic fixtures only.
