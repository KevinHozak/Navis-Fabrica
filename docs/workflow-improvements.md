# Workflow improvement records

The caller-owned dev-improve skill and evaluation guide use the shared [delivery contract](issue-delivery-contract.md). Skill instructions remain in the caller's skill repository; Fabrica supplies executable helpers. Run `scripts/workflow_evidence.py --help` from this checkout for evidence/checkpoint and bounded evaluation interfaces.

Keep cycle snapshots, run records, prompt/response material, usage and personal configuration in the caller's private state directory outside this public checkout. Public summaries require a separate deliberate redaction step; never copy historical local records into this repository during migration. Existing caller records remain authoritative at their original locations.

See [DHH interview improvement experiments](dhh-ai-improvement-experiments.md) for source-linked proposals, existing coverage and bounded manual evaluations. No implementation phase is selected by that review.
