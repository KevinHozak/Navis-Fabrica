# Issue #71: Avoid a full project scan on every startup

## User Review Required

None. Keep startup reconciliation automatic, delayed, bounded, and visible in the Projects view.

## Acceptance Criteria Mapping

| Requirement | Implementation | Verification |
| --- | --- | --- |
| Restore saved inventory without waiting for traversal or Git refresh | Load persisted entries first, seed the fact cache, and schedule a delayed bounded reconciliation | Inspect startup flow and run focused Rust/frontend checks |
| Background work does not block navigation or project actions | Run reconciliation on the existing worker thread and retain the restored list on errors | Verify state transitions and desktop build/checks |
| Watcher refreshes affected projects only | Include changed paths in watcher events and refresh only candidate repository directories | Focused scanner/watcher checks |
| Manual refresh reconciles additions, removals, renames, and moves | Keep the explicit Refresh projects action as the full configured-depth reconciliation, subject to the scanner's safety cap | Existing scanner reconciliation coverage plus checks |
| Bounded missed-event fallback | Use a small startup discovery budget and a periodic safety-capped reconciliation that refreshes Git facts; preserve cached inventory on incomplete scans | Check scan cap and preservation path |
| Root or discovery setting changes reconcile fully | Detect root, exclusions, hidden-folder, and depth changes and request a forced scan | Settings flow verification |
| Errors keep inventory and show freshness | Preserve existing entries and expose stale/refreshing/error status | Frontend checks and desktop build |

## Proposed File Changes

- `src-tauri/src/scanner.rs`: bounded directory budget and single-directory project refresh helper.
- `src-tauri/src/lib.rs`: restore cache without refreshing all Git facts, pass watcher paths, implement affected-project refresh, and trigger full scans after discovery setting changes.
- `src-tauri/capabilities/default.json` and `src-tauri/permissions/autogenerated/start_affected_project_refresh.toml`: authorize the narrowly scoped new command.
- `src/App.tsx`: delayed startup fallback, targeted watcher refresh, settings-change handling, and freshness feedback.
- `src/settings.ts`: typed Tauri API/event helpers for affected refresh and discovery-setting changes.
